# Compositional LLM Routing via Subtask Decomposition and Query–Model Embeddings

## Abstract

LLM routing addresses the growing diversity of language models by selecting from a heterogeneous pool of models to answer input queries. Existing routing methods typically operate at the query level, assigning a single model to handle the entire request. This coarse abstraction, however, overlooks the compositional nature of many real-world tasks, which consist of multiple reasoning steps that may place different demands on model capabilities. We propose *subtask-level routing*, in which each decomposed component of a query is routed independently to the most suitable model. Using two structured datasets with gold decompositions and a pool of eight models, we construct full-question and per-subtask binary correctness matrices that establish upper bounds on routing performance. Our analysis reveals that, given a perfect router, subtask-level routing yields the largest gains on sufficiently complex queries with greater subtask diversity. We adapt and evaluate two existing accuracy-based routing approaches, EmbedLLM and Model-SAT, and find that both fall short of the perfect oracle router. To narrow the gap between oracle upper bounds and practical routing performance, we introduce two original routing methods that improve on existing baselines.
